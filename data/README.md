# Dataset Documentation

This folder contains the cleaned datasets used for the RappiPlus analysis and Power BI dashboard.

## Files

### `orders_clean.csv`

Cleaned transactional order data containing information about:

* Orders
* Customers
* Dates
* Countries
* Devices
* Traffic sources
* Products
* Quantities
* Prices
* Discounts
* Revenue

### `catalog_clean.csv`

Product catalog containing product categories and unit costs.

### `marketing_clean.csv`

Marketing investment data containing spending information by date and acquisition channel.

## Data Privacy

The datasets included in this repository are prepared for educational and portfolio purposes. No sensitive personal information is intentionally included.
